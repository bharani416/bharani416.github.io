Computer vision

Smart PPE Compliance System

Final-year team project, Dept. of AIML, Cambridge Institute of Technology, 2025-26

A camera-based checker for laboratory safety gear. It spots masks, gloves, lab coats, goggles and head covers, tells proper use from improper use, identifies the person by QR code and speaks a warning when something is wrong.

How it works

  1. A webcam on a Raspberry Pi 4 sends a frame twice a second to a FastAPI server.
  2. A Faster R-CNN model (ResNet-50 FPN, PyTorch) finds each PPE item and marks it proper or improper.
  3. The client draws green and red boxes live. If anything is improper, it scans for the person's QR code with pyzbar.
  4. gTTS speaks a personal alert such as "Name, please correct your PPE", or a general one if no QR is found.

What was hard

  • Latency. Every HTTP round trip added 200 to 300 ms. I limited calls to two per second, lowered the input resolution and froze batch-norm layers to cut CPU load.
  • Overlapping audio. Alerts stacked on top of each other. A busy check on the mixer and pre-generated standard messages fixed it.
  • QR codes in dim light. Grayscale conversion and denoising before decoding made scanning dependable.

Built with Python, PyTorch, torchvision, Faster R-CNN, OpenCV, FastAPI, Raspberry Pi 4, pyzbar, gTTS, pygame. Related: IEEE conference paper (2026) on PPE detection.

AI-Powered IT Support & Analytics Platform

My most recent project

An end-to-end platform where employees raise IT tickets, Generative AI sorts and prioritises them, and support leads see the whole picture on a dashboard.

  1. TicketEmployee reports an issue in the web interface
  2. SQL databaseTickets and users are stored
  3. FastAPIA Python REST API processes each ticket
  4. Generative AICategory, priority and suggested troubleshooting steps
  5. Power BIVolume, categories, priority, resolution time, repeat problems

What it does

  • Employees create and track their own IT tickets.
  • AI categorises each issue, sets its priority and drafts troubleshooting steps for the support team.
  • A Power BI dashboard shows ticket volume, issue categories, priority levels, resolution times and recurring problems.

How I kept it reliable

  • API endpoints tested with Postman.
  • Unit tests written with PyTest.
  • A GitHub Actions pipeline runs the tests automatically as the code changes.

What I took from it: building REST APIs, working with relational databases, plugging in an AI service, testing, analysing operational data and setting up a basic CI workflow.

Built with Python, FastAPI, SQL, REST APIs, Generative AI, Power BI, Postman, PyTest, Git and GitHub, GitHub Actions.

Android app

Kreeda-Prerana Scout

Built during my Generative AI internship at MindMatrix, Feb to May 2026

A sports talent tracking app that helps schools find and support young athletes. Many schools, especially in rural and underserved areas, still record sports results by hand and have no way to spot talent early. This gives PE teachers and coaches one place to track every student's performance over time.

What it does

  • Athlete profile management for each student.
  • Sprint timing and distance tracking.
  • Leaderboards that encourage healthy competition.
  • Milestone badges for achievements.
  • Talent Curve visualisation to see how an athlete improves.

Why it matters

Digital records replace manual record-keeping, so results are more accurate and easier to access. Early talent identification also supports grassroots sports development and equal opportunity for students regardless of where they live, in line with goals like Khelo India.
